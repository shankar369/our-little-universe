# Photo Universe Photos

Place Photo Universe images in this folder.

Use paths like `/photoUniverse/universe-01.jpg` from `src/content/photoUniverse.ts`. Keep the file names in the content JSON-like array so the display order, text, and photo path stay easy to edit.

For smooth mobile performance, prefer compressed JPG, WebP, or AVIF images around 512-768px wide for globe thumbnails. Larger originals can be kept elsewhere if needed.

If an image is missing, the 3D sphere and reveal modal show designed placeholders so the section remains usable while real photos are being added.
