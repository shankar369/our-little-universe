# Our Little Universe

A mobile-first birthday memory website built as a romantic, funny, cinematic gift experience.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS v4
- Motion
- tsParticles
- lucide-react

## Project Shape

- `src/app`: app constants and the experience registry.
- `src/content`: typed personal content.
- `src/design`: shared motion and visual constants.
- `src/features`: feature screens and future app sections.
- `src/shared`: reusable components, hooks, and utilities.
- `docs`: maintainability notes and roadmap.
- `.codex/skills/our-little-universe`: project-specific working instructions.

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`

## Current Phase

Phase 1 is live: soft login gate, ambient particles/hearts, and opening hero.

See `docs/maintainability.md` before adding major features.
